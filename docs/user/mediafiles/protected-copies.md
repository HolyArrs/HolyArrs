# Protected copies

You have a movie or show file you like, and you never want an upgrade to replace it. Protect it.

## Protect a copy

1. Open the title page.
2. Go to the **Copies** section.
3. In the Version's group, select **Protect this copy**.

The copy shows a **Protected** badge. Protection stays through restarts and rescans, even while the file is missing for a while.

Before a search result is used and before an import places a file, HolyArrs checks protection again. An older search or a download already queued cannot replace a protected copy.

## Keep a copy and add another Version

Use this when you want a second copy beside this one, such as 4K next to HD.

1. Select **Keep this copy and add another Version**.
2. Choose a label, a Library folder and Pick rules. You can also add an edition and audio languages.
3. Select **Protect and add Version**.

HolyArrs protects the copy and adds the Version in one step. If it fails, nothing changes. It does not start a download and does not copy the file into the new Version.

## Remove protection

1. In the copy's group, tick the box that confirms you want to remove protection.
2. Select **Remove protection**.

## What protection does when you delete

- Removing a title or a movie series skips a protected title and keeps it in your Library.
- Removing files by hand can include protected copies if you confirm that separately. Only files HolyArrs imported or took over move to the holding folder. Other files stay where they are.
- When that move works, protection is cleared, and holding cleanup can remove the file later. When the move fails, the copy stays protected.
- Holding cleanup skips protected files.

For a show file that covers several episodes, a season pack cannot replace part of it while it is protected.

Protection does not change other titles, Versions or Pick rules.

## Troubleshooting

**Remove protection is greyed out.** Tick the confirm box first.

**A protected file changed anyway.** Protection only covers what HolyArrs does. Another program, or someone working on the disk directly, can still change the file.

**The codec list will not let you select a copy.** Protected copies cannot be searched again. See [Video codecs](library-codecs.md).

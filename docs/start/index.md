Go from an empty server to your first title in five steps. Do them in order.

1. [Install](./install/): run HolyArrs in Docker and open it on port `6262`.
2. [Folders](./folders/): put downloads and library under one parent folder so imports move instantly.
3. [First run](./first-run/): make the owner account and answer the setup steps.
4. [Connect](./connect/): link one downloader and one source. The test must pass.
5. [First title](./first-title/): add a movie and watch it search, download and import.

After step 5, [Home and Settings](./home-and-settings/) shows where everything lives.

Coming from Sonarr, Radarr or other apps? Pick **Bring my apps** in step 3. See [Moving from other apps](../migrate/).

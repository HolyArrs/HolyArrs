Report a broken file: bad picture, drifting sound, wrong subtitles or no playback. The owner or an admin fixes it.

Reports live at **Requests > Reports** (`http://your-server:6262/requests/reports`).

## Send a report

1. Open the movie, show or album.
2. Choose **More > Report a problem**.
3. Pick **Picture**, **Sound**, **Subtitles**, **Won't play** or **Other**.
4. Add a note if it helps, for example "sound drifts after 20 minutes".
5. Send it.

You should see it under **Requests > Reports**. You can report a whole title, a season, an episode, an album or a track.

## Answer a report

The owner and admins see every report. Members see only their own.

1. Open **Requests > Reports** and open the report.
2. Fix the file, for example by swapping in a better copy.
3. Press **Mark fixed** and add a note. The reporter sees it.

Fixed reports stay in the list. Press **Reopen** if the problem comes back.

## If it does not work

**Symptom:** there is no **Report a problem** option.
**Cause:** reports are for titles in the Library. **Fix:** open the title page itself.

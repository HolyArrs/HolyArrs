Paste this into your AI assistant and replace the last part with your idea:

```text
Read https://holyarrs.com/ai/plugin.md and help me make a HolyArrs plugin. My idea: <describe it here>
```

The assistant reads the full guide first. It asks before it pushes code or opens a pull request.

Plugins work in HolyArrs 1.2.1 and newer.
